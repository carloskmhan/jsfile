Language rule maintenance

Customer names and IDs are read from the authenticated Tableau group-index worksheet. There is no aliases.csv customer master in this version.

Edit the seven language CSVs with the local English workbench:

python rule_manager.py

Or compile approved CSV edits directly:

python build_command_patterns.py

Rules: commands.csv, synonyms.csv, followups.csv, settings.csv, fuzzy_config.csv, units.csv, temporal.csv. Validate and review before replacing command_patterns.txt on the approved web host.

The local workbench does not automatically deploy changes. See COMMANDS.md and TABLEAU_SETUP.md.
